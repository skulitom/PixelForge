PixelForge Studio
=================

The pixel-art tool your coding agent can drive. Sprites and animations are
editable JSON recipes; PixelForge turns them into PNG sprite sheets, animated
PNGs and atlas metadata, the same way every time. There are three ways in:
a studio in your browser, a command line, and an MCP server for agents.

This folder is self-contained. It brings its own copy of Node.js, so there is
nothing to install, no account and no image model. Keep the folder's contents
together. To remove PixelForge Studio, stop it and delete the folder.


1. Open the studio
------------------

Double-click "PixelForge Studio.cmd".

A console window opens, prints the studio's address and opens it in your
default browser. The address looks like http://127.0.0.1:50123/ and the number
changes on each start. The studio listens on this computer only. Close the
console window to stop it.

Windows may ask before it runs a file that came from the internet.
"PixelForge Studio.cmd" is a short text script; you can read it in Notepad.

In the studio, pick a sample on the left and edit its JSON on the right. The
preview updates as you type. "Save JSON" downloads your recipe and "Open
project" loads it again. There is no autosave, so save before you close the
tab. "Export assets" downloads a ZIP with the sprite sheet, every frame, the
animations and a preview.html that plays from disk.

The studio inspects and edits recipes. It is not a paint program.


2. Use the command line
-----------------------

Open a terminal in this folder: in File Explorer, click the address bar, type
cmd and press Enter. The commands below work in Command Prompt and PowerShell.

    .\pixelforge init hero.pixel.json
    .\pixelforge validate hero.pixel.json
    .\pixelforge inspect hero.pixel.json --out hero-frames.png
    .\pixelforge patch hero.pixel.json --changes first-edit.json --out hero-v2.pixel.json
    .\pixelforge render hero-v2.pixel.json --out output\hero

init writes an editable copy of the forest spirit sample. validate checks it.
inspect saves a contact sheet of every frame. patch applies the two small
changes in first-edit.json, lists every pixel they alter and saves the result
as a new recipe. render exports the complete asset bundle; open
output\hero\preview.html to watch it play.

Existing files are never replaced unless you add --force. Run
".\pixelforge help" for every command.


3. Connect your coding agent
----------------------------

Double-click "Connect your agent.cmd".

It prints MCP settings for Claude Code, Claude Desktop, Codex and Cursor with
this folder's paths already filled in. Copy the block for your agent into its
settings. The helper only prints: it never changes a configuration file. If
you move this folder, run it again.

Then ask your agent to call pixel_help. What the agent renders is saved in the
"output" folder here.

PixelForge is for small sprites, tiles and effects: up to 256 x 256 pixels and
256 frames per recipe.

The Emberfall and Tidewatch demos are in the GitHub repository, not this ZIP.
